## ✅ O que a [Salete Firmino](https://www.office.com/search?q=Salete+Firmino&EntityRepresentationId=b94204fe-99f1-4e46-b8e3-500cc42b2d2e) quer

Ela precisa que você levante **quais usuários estão gerando custo** em dois fornecedores:

- **Hinfoluz**
- **TD Synnex**

E que você organize isso **por centro de custo**.

👉 Objetivo deles: usar essa informação pra **ratear (dividir) os custos corretamente** entre:

- TAC
- contratos ativos

👉 Prazo: **até 25/06**

## 🧠 Traduzindo pra linguagem prática de TI

Ela está pedindo basicamente um**“mapeamento de usuários x custo x centro de custo”** dessas cobranças.

## 🛠️ O que você pode fazer (passo a passo direto)

### 1. Levantar os usuários dessas cobranças

- Hinfoluz → normalmente ligado a serviços/infra/suporte (ver contratos/faturamento)
- TD Synnex → pode ser licenciamento, Microsoft, hardware, etc.

➡️ Você precisa identificar **quem usa o quê que está sendo cobrado**.

### 2. Cruzar com centro de custo

Para cada usuário, identificar:

- Nome
- O que ele consome (licença/serviço)
- Centro de custo

📊 Exemplo simples:

```
Usuário           | Serviço           | Fornecedor    | Centro de Custo
João Silva        | M365 E3           | TD Synnex     | Administrativo
Maria Souza       | Sistema X / infra | Hinfoluz      | Produção
```

### 3. Separar por fornecedor

Fazer dois blocos:

- Hinfoluz
- TD Synnex

(ou duas abas, se for Excel)

### 4. Validar inconsistências

- Usuário sem centro de custo
- Licenças não atribuídas claramente
- Custos compartilhados (ex: servidor)

### 5. Entregar o “estudo”

Pode ser:

- Excel (melhor opção)
- Ou lista estruturada no e-mail

## ⚠️ Pontos de atenção (importante pra você)

- Provavelmente você vai precisar puxar:
    - AD / cadastro de usuários
    - Licenças (Microsoft 365, etc.)
    - Informações de contratos/fatura
- Pode ter coisa que **não está clara**, então é válido alinhar

## 💡 O que está acontecendo aqui

Pelo e-mail da [Salete Firmino](https://www.office.com/search?q=Salete+Firmino&EntityRepresentationId=b94204fe-99f1-4e46-b8e3-500cc42b2d2e), ela não está pedindo o rateio em si — isso é do Financeiro/ADM.

👉 Ela está pedindo **a base de dados**:

- “relação de usuários”
- vinculados aos custos (Hinfoluz / TD Synnex)
- separados por centro de custo

E quem normalmente tem isso? ➡️ **TI** (porque envolve usuários, licenças, acessos, etc.)

## 🎯 Então respondendo sua pergunta

### ❌ Não é função de TI:

- Definir critério de rateio
- Fazer cálculo financeiro
- Decidir como dividir custo

### ✅ Mas pode cair pra TI:

- Levantar **quem usa o quê**
- Relacionar usuários ↔ serviços/licenças
- Ajudar com dados técnicos que ninguém mais tem

## ⚠️ Onde você precisa se posicionar (importante)

O risco aqui é você virar:

> “TI responsável pelo rateio financeiro” ❌

E isso **não pode**.
