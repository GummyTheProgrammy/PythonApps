# XMLNexus

Projeto para processamento e análise de arquivos XML, com foco em extrair, validar e organizar dados de remessas em formatos estruturados.

## Estrutura

- `xmlnexus/` — código principal do aplicativo
- `xmlnexus/dist/` — distribuição compilada em `.exe`

## Observação

A distribuição executável é a parte que deve ser mantida no repositório. Os artefatos intermediários de build e arquivos temporários ficam ignorados pelo `.gitignore`.
