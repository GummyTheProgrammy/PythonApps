# Dados

Nesta pasta estão os projetos relacionados a processamento de dados e conversões:

- `limpa_csv` — scripts para limpeza e normalização de CSVs
- `XMLNexus` — processamento e validação de arquivos XML (distribuição .exe mantida)
- `qr-code-gen` — ferramentas para geração de QR codes
- `split-pdf` — divisão de arquivos PDF em partes menores
- `presentation-notes` — geração de conteúdo para apresentações e exportação de `.pptx`

Cada subpasta contém seu próprio README com instruções de uso.
